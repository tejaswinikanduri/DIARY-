# My Diary — GitHub Pages

A responsive, block-style personal diary website inspired by the reference screenshot.

## Publish free with GitHub Pages
1. Create a GitHub repository (for example `my-diary`).
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose `main` and `/ (root)`, then Save.
6. Open the Pages URL GitHub gives you.

## Important privacy and storage notes
- This is a static website, not an APK. It works in a browser on Android and desktop.
- Entries and settings are stored in that browser's local storage on that device. They do not automatically sync to another phone or browser.
- Export a JSON backup regularly from Settings. Import it on another device to restore.
- Photos are stored in browser storage as data URLs; keep individual photos under 2 MB. Browser storage limits apply.
- The PIN is a convenience lock only; it is not encryption. Do not store highly sensitive information.
- Google Fonts are loaded from the internet. The rest of the app is a single HTML file.
